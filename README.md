EMBERFALL — a lantern-defense arcade game: keep the last lantern lit, burn the wisps with flares, gather their embers, and survive ten nights until dawn.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. Move with WASD or the arrow keys, flare with Space or a click, pause with P, sound with M.
